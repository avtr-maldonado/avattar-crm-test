# Activos de marca

Del manual de normas gráficas de Avattar. **No modificar ni recolorear**: el
manual es la fuente, y §13.1 del spec dice que los tokens se copian
textualmente.

| Archivo | Uso |
|---|---|
| `avattar-blanco.png` | 534×200 RGBA. Para fondos oscuros — la barra lateral navy |
| `avattar-color.svg` | Azul de marca. Para fondos claros |

`avattar-color.svg` es un PNG incrustado en un envoltorio SVG, no un vectorial
de verdad: no escala sin perder nitidez por encima de 1150 px de ancho. Si se
necesita a mayor tamaño, pedir el vectorial original a diseño.
